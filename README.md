# CSCE-490-Research-Milestone
Sample project learning chosen frameworks and technologies for Capstone project development.

Frameworks being used for project:
* Java Spring Boot (web application framework, back-end) - Tutorial https://youtu.be/gJrjgg1KVL4?si=fYFS1uyRpfh74XMb
* React (front-end)
* PostgreSQL (database)
* Spring Data JPA (handle database operations within Java)
* React Native (mobile development framework)
